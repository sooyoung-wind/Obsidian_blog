### 📝메모 

#### 0단계 인사하기
- 입사 첫날이므로 멘토링해주는 사람이 있으면 그 사람을 통해서 같이 일한 동료 직원들에게 인사하기
- 보통 동료 직원들이 명함을 주면 받아서 잘 챙겨두자
- 초반에는 사람이 많아서 이름, 직급, 직책을 다 외우지 못하니 명함을 받아서 보관하면서 책상 위치를 통해서 외워가자

#### 1단계 환경 세팅
**노트북 초기 세팅(윈도우)**
- 윈도우 패스워드 설정
- 와이파이 설정(회사 공유기 ID/PW)
- VPN 설치 및 보안 프로그램 설치
- 외부 저장장치 사용 여부 확인(USB 등)
- 프린터 및 공유 폴더 접근 권한

**회사 계정(ID) 받기**
- 회사 계정으로 microsoft 계정 만들기 (회사 정책)
- 회사 계정으로 구글 계정 만들기 (회사 정책)

**문서 편집기**
- 한글 또는 오피스 라이센스 받기
- 라이센스가 없다면 회사에서 사용할 수 있는 무료 오픈 소스 프로그램을 사용하자 
	- 압축 프로그램 : 반디집(https://kr.bandisoft.com/bandizip/)
	- PDF 프로그램 : nPDF(https://iblogbox.com/npdf/)

**AI Tool**
- 생성형 AI
	- Gemini, ChatGPT, Perplexity 등(microsoft store에 있음)

**메신저 및 협업 Tool**
- Slack, Teams 등 로그인
- 회사 메일 설정
- 협업 Tool(Jira, Notion, Confluence 등)
- FTP 프로그램
	- 파일질라(FileZilla) : [다운로드](https://filezilla-project.org/download.php)

**개발 환경**
- IDE(cursor ai, vscode, kiro 등)
- 리눅스 환경 WSL2 셋팅
- 클라우드 관련 접속 확인 및 ID 받기

**개인 관리 프로그램**
- 근태 관리(회사내 프로그램이 있으면 제외)
	- 없으면, Jibble 사용 (https://www.jibble.io/)
	- 모바일도 가능함
- Trello(회사내 협업 프로그램에 따라 변경)
	- To do list 관리
	- microsoft store에 있음
- Git
- GitHub desktop
- Chocolate
- WSL2 ([설치 및 연동 블로그](https://cuffyluv.tistory.com/245))
- notepad++
- obsidian
- 브라우저(네이버웨일, 엣지, Comet)

#### 2단계 코드 규칙 파악
**코드 규칙 관련 문서 읽기**
- GitHub orgnization 초대 받은 후
- READMD 읽기
- 브랜치 전략 확인
- CI/CD 파이프라인 개요 / 실패 시 연락망
- 코드 스타일/포맷터 규칙
- 마지막으로 오타 수정과 같이 리스크가 없는 PR 시도하기
