#### 새로운 폴더 정리 방법

- 폴더 이름은 `예) 000, 100, 200, ...`와 같이 백 단위로 대분류, 중분류, 소분류로 구분한다.
- 숫자가 낮을 수록 중요한 파일로 인식하고 `900`대 숫자는 임시파일 또는 개인 파일로 분류한다.
	- 지금 현재 `99_개인자료` -> `900_개인자료` 
	- 임시 파일 `999_임시파일` : 삭제 주기 1달 이내

#### 파일명 정리 방법(파일 생성)
- 파일명 :`날짜_업무구분_(원제목)_버전_작성자`
	- 예시 : `250823_개인_잡코리아-이력서_REV00_김사원_final`
	- 일자는 `yymmdd` 형식
	- 업무구문 : 개인, 공통, 회계 등
	- 원제목 : 파일 제목의 띄어쓰기는 하이픈(-)으로 해서 파일명이 깨지지 않게 함
	- 버전 : `REV00`은 최조 작성 문서, `REV01~99`은 수정된 파일
	- 작성자 : 작성자의 실명
	- final (유/무) : 만약 최종 결재된 문서 파일일 경우 `_final` 소문자로 맨 뒤에 표기해서 쉽게 찾을 수 있도록 함

#### 파일명 정리 방법(수신 파일 관리)
- 파일명 : `수신날짜_기관명_문서종류_(원제목)`
- 예시 : `20250823_환경청_보고서_환경조사결과.pdf`
- 수신날짜 : `yyyymmdd`
- 기관명 : 환경부, 중소기업청 등
- 문서종류 : 공문, 보고서, 안내문, 협약서 등
- 원제목 : 키워드 또는 문서 제목

> 문서가 월마다 많다면 월별 폴더를 추천. 문서가 적다면 연도별로 정리 추천



```yaml
📂 외부문서
 ┣ 📂 2025
 ┃ ┣ 📂 08
 ┃ ┃ ┣ 20250823_교육부_공문_사업계획.pdf
 ┃ ┃ ┣ 20250823_환경청_보고서_환경조사결과.pdf
 ┃ ┃ ┗ 20250824_중소기업청_공문_협약체결.pdf
 ┗ 📂 2024

```
