### 📝메모 

PyCaret은 파이썬(Python)으로 작성된 오픈 소스 머신 러닝 라이브러리로서, 코드 작성을 최소화하여 머신 러닝 실험을 빠르고 쉽게 수행할 수 있도록 설계되었습니다. **Low-code** 환경을 제공하여 복잡한 머신 러닝 모델의 구축, 비교, 최적화 과정을 간소화하고 자동화합니다.

PyCaret Github : https://github.com/pycaret/pycaret

# PyCaret ?

## **주요 특징**

### **1. 다양한 머신 러닝 작업 지원**

- **분류(Classification)**
- **회귀(Regression)**
- **클러스터링(Clustering)**
- **이상치 탐지(Anomaly Detection)**
- **자연어 처리(Natural Language Processing)**
- **시계열 예측(Time Series Forecasting)**

### **2. 사용자 친화적인 인터페이스**

- 복잡한 알고리즘과 파라미터 튜닝 과정을 단순화하여, 몇 줄의 코드로 다양한 모델을 구축하고 비교할 수 있습니다.

### **3. 자동화된 머신 러닝 워크플로우**

- 데이터 전처리, 특징 공학, 모델 학습, 하이퍼파라미터 최적화, 모델 평가 및 배포까지의 전 과정을 자동화합니다.

### **4. 통합 및 확장성**

- **Pandas**, **NumPy**, **scikit-learn** 등과 같은 인기 있는 파이썬 라이브러리와 통합되어 있으며, **TensorFlow**, **PyTorch** 등의 딥러닝 프레임워크와도 연동이 가능합니다.

# PyCaret Install

PyCaret은 poetry를 통해서 설치가 가능하다. 다른 라이브러리들과의 호환을 위해서 poetry를 추천합니다.

```bash
poetry add pycaret
```

> **python 3.11 추천**
2024.10.31 기준으로 pycaret은 python 버전이 3.12까지만 호환되고 있다. 하지만 다른 패기지 문제로 python 3.11을 추천한다.

# **기본 사용 예시**

다음은 PyCaret을 사용한 간단한 분류 모델 구축 예시입니다:

```python
import pandas as pd
from pycaret.classification import *

# 데이터 로드
data = pd.read_csv('data.csv')

# 환경 설정
s = setup(data, target='target_column')

# 모델 비교
best_model = compare_models()

# 특정 모델 생성
model = create_model('lightgbm')

# 모델 튜닝
tuned_model = tune_model(model)

# 모델 평가
evaluate_model(tuned_model)

# 모델 저장
save_model(tuned_model, 'best_model')
```

## **장점**

### **1. 효율성**

- 몇 줄의 코드로 복잡한 머신 러닝 작업을 수행할 수 있어 개발 시간을 절약합니다.

### **2. 비교 및 선택의 용이성**

- 다양한 알고리즘을 쉽게 비교하여 최적의 모델을 선택할 수 있습니다.

### **3. 자동화**

- 반복적인 작업을 자동화하여 실험 효율을 높입니다.

### **4. 교육용으로 적합**

- 머신 러닝 입문자들이 전체 프로세스를 이해하는 데 도움이 됩니다.

---

## **주의사항 및 한계**

- **유연성 제한**: 자동화된 환경이기 때문에 세부적인 제어가 필요한 경우 한계가 있을 수 있습니다.
- **성능 최적화**: 복잡한 커스텀 모델이나 특수한 데이터셋에 대해서는 최적의 성능을 내기 어려울 수 있습니다.
- **버전 호환성**: 다양한 라이브러리와 통합되어 있으므로, 버전 호환성에 주의해야 합니다.

---

## **활용 분야**

- **프로토타이핑**: 빠른 모델 개발 및 테스트가 필요한 경우.
- **교육 및 학습**: 머신 러닝의 전 과정을 이해하고자 하는 학생이나 초급 개발자.
- **업무 자동화**: 반복적인 머신 러닝 작업을 자동화하여 생산성 향상.

---

## **결론**

PyCaret은 머신 러닝 작업을 간소화하고 자동화하여 개발자와 데이터 과학자의 생산성을 높여주는 강력한 도구입니다. Low-code 환경을 통해 복잡한 머신 러닝 프로세스를 쉽게 다룰 수 있으며, 빠른 실험과 프로토타이핑에 적합합니다. 그러나 유연성이 필요한 고급 사용자나 특수한 요구 사항이 있는 경우에는 제한이 있을 수 있으므로, 이러한 경우에는 기존의 머신 러닝 라이브러리와 병행하여 사용하는 것이 좋습니다.
