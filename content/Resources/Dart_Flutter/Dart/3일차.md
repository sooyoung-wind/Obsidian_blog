### 1. 함수 정의
Dart에서 함수를 정의하려면 `returnType functionName(parameters)` 형식을 사용

- **기본 형식**: 반환 값이 있는 함수
- **반환 값이 없는 함수**: 반환 타입을 `void`로 명시
- 함수 본문은 중괄호 `{}`로 감쌈

예시)
```dart
int add(int a, int b) {
  return a + b;
}

void printMessage(String message) {
  print(message);
}

```

#### 1.1 함수 이름 규칙

1. **소문자로 시작** 
    - 함수 이름은 항상 소문자로 시작해야 함
    - 예: `getName()`, `calculateSum()`.
2. **단어 간 연결은 `camelCase` 사용**
    - 함수 이름이 여러 단어로 이루어진 경우, 첫 단어는 소문자로 시작하고 이후 단어의 첫 글자는 대문자로 작성.
    - 예: `getUserInfo()`, `calculateTotalPrice()`.
3. **특수 문자 사용 금지**    
    - 함수 이름에 공백, 하이픈(`-`), 또는 기타 특수 문자를 사용할 수 없음.
    - 대신 밑줄(`_`)은 사용 가능하지만 Dart에서는 일반적으로 `camelCase`를 권장함.
4. **숫자로 시작 금지**    
    - 함수 이름은 숫자로 시작할 수 없음.
    - 예: `1calculateSum()` (잘못된 예).
5. **키워드 사용 금지**    
    - `class`, `void`, `if` 등 Dart의 예약어(키워드)는 함수 이름으로 사용할 수 없음.

### 2. Named parameters
Dart에서는 함수 호출 시 매개변수를 이름으로 전달할 수 있습니다. 이는 매개변수의 순서에 구애받지 않도록 합니다.

- **Named Parameter**는 중괄호 `{}`로 묶습니다.
- 기본값을 설정하거나 `required` 키워드를 사용할 수 있습니다.

예시)
```dart
void greet({required String name}) {
  print('Hello, $name.');
}
```

**실습 문제 1** 이름과 나이를 입력받아 메시지를 출력하는 함수를 작성하세요. 나이가 입력되지 않으면 "알 수 없음"으로 출력하세요.

```dart
void printNameAge({required String name, String age = "unknown"}) {
  print("Hello, my name is $name, I am $age");
}

void main() {
  printNameAge(name: "Soyoung");
}
```

**실습 문제 2** 이름과 점수를 입력 받아 학생의 성적을 출력하는 함수를 작성하세요. 점수는 기본 값으로 50을 사용하세요.

```dart
void printNameScore({required Sting name, double score = 50}){
	print("Name : $name, score : $score");
}
```

### 3. Positional parameters

Dart에서는 선택적인 위치 매개변수도 지원합니다. `[]` 안에 매개변수를 정의하면 선택 사항이 됩니다.

예시)
```dart
void describe(String name, [int? age, String? city]) {
  print('Name: $name');
  if (age != null) print('Age: $age');
  if (city != null) print('City: $city');
}

// or

void describe(String name, [int? age = null, String? city = null]) {
  print('Name: $name');
  print('Age: $age');
  print('City: $city');
}

```

**실습문제 1** 삼각형의 밑변과 높이를 받아 면적을 계산하는 함수를 작성하세요. 밑변과 높이가 제공되지 않으면 기본값 1을 사용하세요.

```dart
void calTriangleArea([double base = 1, double height = 1]) {
	print("Area : ${0.5 * base * height}");
}

void main() {
	calTriangleArea(2, 2);
}
```

### 4. QQ Operator
QQ 연산자 `??`는 null 값을 처리하기 위해 사용된다. `??`를 통해 null 대신 기본값을 제공할 수 있다.
- 물음표(`?`) : 변수나 타입 뒤에 물음표를 붙이면 그 변수는 null 값을 가질 수 있다는 의미이다.

```dart
String? name; // name 변수는 null일 수 있습니다.
```

- 물음표 2개(`??`) : 물음표 2개를 사용하면 널 병합 연산자로 왼쪽 연산자가 널이면 오른쪽 피연산자를 반환한다.

```dart
String? name;
print(name ?? 'Unknown'); // name이 null이면 'Unknown'을 출력합니다.
```


```dart
String capitalizeName(String? name) {
	if ( name != null) {
		return name.toUpperCase();
	}
	return 'ANON';
}

// or

String capitalizeName(String? name) +> name != null ? name.toUpperCase() : "ANON";

// or

String capitalizeName(String? name) +> name?.toUpperCase() ?? "ANON";
```

- **??=** 는 좌변에 있는 피연산자가 널이면 우변에 있는 피연산자로 할당하라는 연산자이이다.

```dart
void main() {
	String? name;
	name ??= "Sooyoung";
	print(name); // Sooyoung
}
```

**실습 문제 1** : 사용자의 이메일을 받아 null일 경우 "이메일 없음"을 출력하세요.

`print(${email} ?? "이메일 없음");` 아니고 `print(email ?? "이메일 없음");`라고 작성하는 이유는 먼저 `email` 변수가 널인지 아닌지 판단한 다음에 `print`문이 실행되기 때문이다. 
```dart
void emailAddress([String email]) {
	print(email ?? "이메일 없음");
}

void main() {
	emailAddress();
}
```

문자열로 구성하고 싶으면 아래와 같이 작성한다. 
```dart
void emailAddress([String? email]) {
  print("당신의 이메일은 ${email ?? '이메일 없음'}입니다.");
}

void main() {
  emailAddress();
}
```

### 5. Typedef
`Typedef`는 복잡한 함수 타입에 별칭을 제공하는데 사용합니다.

```dart
List<int> reverseListOfNumbers(List<int> list) {
	var reversed = list.reversed;
	return reversed.toList();
}

// apply Typedef below

typedef ListOfInts = List<init>;

ListOfInts reverseListOfNumbers(ListOfInts list) {
	var reversed = list.reversed;
	return reversed.toList();
}

```
