### 1. class 선언

dart에서는 class 선언을 주로 사용하고 class의 이름은 주로 대문자로 시작한다. `void main`과 같이 중괄호 `{}`로 구분하고 class에서 선언되는 변수는 **반드시** 타입을 선언해야 한다. `var` 선언이 안된다는 뜻임.

class 내부에서 `this.name`과 같이 `this`라는 문구를 사용하여 class의 속성임을 명시할 수 있는데 반드시 사용할 필요는 없다. 단, class내 함수에서 동일한 이름의 변수명이 있다면 서로 구분하기 위해서 `this.name`은 class의 속성 변수이고 `name`은 함수 내에 선언된 변수임을 의미한다.

- property
- method

```dart
class Player {
	// 변수는 타입을 반드시 명시해야 한다. class에서 var 사용 불가능
	fianl String name = "Sooyoung";
	int xp = 1500;

	void sayHeelo() {
		print("Hi my name is $name");
		// print("Hi my name is $this.name");
	}
}
```

### 2. Constructors

생성자(Constructors)를 사용해서 class의 인스턴스를 생성할 때 객체의 속성을 입력 받은 파라미터로 초기화가 가능하다. Dart에서는 기본 생성자뿐만 아니라 사용자 정의 생성자도 만들 수 있으며, 생성자는 클래스 이름과 동일하게 정의된다.

```dart
class Player{
	// late를 사용해서 final이지만, 나중에 입력 받을 수 있게 설정함
	late final String name;
	late int xp;

	Player(String name, int xp) {
		this.name = name;
		this.xp = xp;
	}
}

void main() {
	var player = Player('Sooyoung', 1500);
	print("${player.name}, ${player.xp}");
}
```

이제 생성자를 좀 더 심플하게 만들어보자.
```dart
class Player{
	final String name;
	int xp;

	Player(this.name, this.xp); // 이렇게 생성자를 한줄로 가능함
	// 단, 지금은 positional parameters이다. 
}
```

### 3. Named Constructor Parameters
Named constructor parameters는 생성자에서 매개변수의 순서를 기억할 필요 없이 이름을 사용해 값을 전달할 수 있게 해준다.
중괄호`{}`를 사용하면 named constructor parameters로 변경이 가능하다. 함수에서 사용하던 방법과 동일함.
```dart
class Player{
	final String name;
	int xp;

	// 기본값을 주던지 required를 주던지...
	Player({required this.name, required this.xp});
}

void main() {
	var player = Player(
		name: "Sooyoung",
		xp: 1500,
	);
	print("${player.name}, ${player.xp}");
}
```

**실습 문제 1** : `Book` 클래스를 생성하고, 이름 있는 생성자를 사용하여 `title`과 `author` 값을 초기화하세요.
```dart
class Book {
  String title;
  String author;

  Book({required this.title, required this.author});
}

void main() {
  var book = Book(title: '1984', author: 'George Orwell');
  print('Title: ${book.title}, Author: ${book.author}');
}

```
### 4. Named Constructor

Named constructor는 클래스를 정의할 때 **여러 생성자**를 제공할 때 사용한다. 이는 `Classname.ConstructorName` 형식으로 생성자를 정의하고, 객체를 생성할 때 특정 목적에 맞는 생성자를 선택할 수 있게 한다.

예시)
```dart
class Player{
	final String name;
	int xp;
	String team;

	Player({required this.name, required this.xp, required this.team});

	Player.createBluePlayer({required String name, required int xp}) :
	this.xp = xp,
	this.name = name,
	this.team = 'Blue';
}

void main() {
	var player = Player.createBluePlayer(
		name: "Sooyoung",
		xp: 1500,
	);
	print("${player.name}, ${player.xp}, ${player.team}");
}
```

### 5. Cascade Notation

Cascade notation(..)은 같은 객체에 대해 여러 메서드 호출이나 속성 설정을 간단히 표현할 수 있도록 도와준다.

아래 예시와 같이 user의 인스턴스를 생성하고 각 속성의 값을 변경하려고 하면 `user.name, user.email`와 같이 일일이 인스턴스의 이름과 함께 속성을 작성해 줘야 한다. 하지만, **cascade notation**을 사용하면 `user`라는 중복되는 단어를 생략할 수 있다.
```dart
class User {
  String name = '';
  String email = '';

  void printUser() {
    print('Name: $name, Email: $email');
  }
}

void main() {
  var user = User();
  user.name = 'Alice';
  user.email = 'alice@example.com';
  user.printUser();
}

```

먼저 `var user = User();`뒤에 세미콜론을 삭제하고 `user`를 전부다 `.`로 표현하며 마지막으로 바꾸는 속성만 제외하고 맨 뒤에 `;`을 전부 다 삭제한다. 이렇게 작성된 코드는 아래와 같다.
```dart
void main() {
  var user = User()
    ..name = 'Alice'
    ..email = 'alice@example.com'
    ..printUser(); // 메서드 호출도 가능함
}
```
### 6. Enums
Enum은 정해진 값 집합을 표현하는 데 사용된다. 예를 들어, 날씨 상태를 `sunny`, `rainy`, `cloudy`와 같이 표현할 수 있다.  
Enum은 `enum` 키워드로 정의하며, switch 문과 함께 사용할 수도 있다.

**실습 문제 1** `Weather` enum을 생성하고, `sunny`, `rainy`, `cloudy` 값을 추가하세요.

```dart
enum Weather { sunny, rainy, cloudly }

void main() {
	var today = Weather.sunny;

	switch (today) {
		case Weather.sunny:
			print('It is sunny!');
			break;
		case Weather.rainy:
			print('It is rainy!');
			break;
		case Weather.cloudly:
			print('It is cloudly!');
			break;
	}
}
```

### 7. Abstract Classes

추상클래스는 인스턴스를 직접 생성할 수 없는 클래스이다. 추상클래스는 자식클래스에서 구현해야 하는 메서드를 포함하고 있다. 상속을 통해 다양한 자식클래스에 공통 기능을 제공하거나, 필수적으로 구현해야 하는 메서드를 개발자가 강제로 구현하도록 할 수 있다.

```dart
abstract class Shape {
  double area();
}

class Circle extends Shape {
  double radius;

  Circle(this.radius);

  @override
  double area() => 3.14 * radius * radius;
}
```

### 8. Inheritance(상속)
상속은 기존 클래스의 속성과 메서드를 재사용하거나 확장하기 위해서 사용된다. Dart에서 샹속은 `extends` 키워드를 사용하며, 자식클래스는 부모클래스의 모든 속성과 메서드에 접근할 수 있다.
또한 `super` 키워드를 통해 부모 클래스의 생성자나 메서드를 호출할 수 있다.

여기서도 `override`를 사용하여 부모클래스에서 정의된 `honk`를 변형했다. 단, `super.honk()`를 호출할 수 있기 때문에 실질적으로 덮어쓰는 행위가 아니고 메서드의 우선 순위가 있다고 보는 것이 좀 더 정확하다고 생각된다.
그리고 메모리 측면에서도 서로 다른 곳에 저장되므로 `override`의 직역인 덮어쓰기는 부적절한 번역이라고 생각된다.
```dart
class Vehicle {
  String brand;

  Vehicle(this.brand);

  void honk() {
    print('Beep!');
  }
}

class Car extends Vehicle {
  String model;

  Car(String brand, this.model) : super(brand); // super(brand)로 부모클래스에 전달

  void showDetails() {
    print('Brand: $brand, Model: $model');
  }

  @override
  void honk() {
    super.honk();
    print("This is Car!");
  }
}

void main() {
  var car = Car('Toyota', 'Camry');
  car.honk();
  car.showDetails();
}

```

### 9. Mixins

Mixin은 코드의 재사용성을 높이기 위해 사용되며, 여러 클래스에 공통적인 기능을 추가할 때 사용된다.
Mixin은 `with` 키워드를 사용하며, 일반적으로 상태를 가지지 않는 메서드의 집합을 정의한다.
Dart에서 Mixin은 추상 클래스와 달리 다중 상속처럼 사용할 수 있다.

**실습 문제 1** 
- `Flyable` 믹스인을 생성하고, `Bird` 클래스에 적용하세요.
- `Bird` 클래스에서 날 수 있는 행동을 나타내는 메서드와 새 이름을 출력하는 메서드를 추가하세요.

```dart
mixin Flyable {
  void fly() {
    print('Flying...');
  }
}

class Bird with Flyable {
  String name;

  Bird(this.name);

  void chirp() {
    print('$name is chirping!');
  }
}

void main() {
  var bird = Bird('Sparrow');
  bird.chirp();
  bird.fly();
}
```

### 10. fromJson

외부 API를 통해서 Json 형태의 데이터를 받고 이를 dart의 class로 구현하게 되어 데이터를 핸들링하게 된다. 이를 위한 기초적인 학습을 해보자.
**named constructor**를 구현해서 사용하면 된다.
```dart
class Player {
	final String name;
	int xp;
	String team;

	Player.fromJson(Map<String, dynamic> playerJson) :
	name = playerJson['name'],
	xp = playerJson['xp'],
	team = playerJson['team'];

	void sayHello() {
		print("Hi my name is $name");
	}
}

void main() {
	var apiData = [
		{
			"name": "Sooyoung",
			"team": "red",
			"xp": 0,
		},
		{
			"name": "Mike",
			"team": "blue",
			"xp": 0,
		},
		{
			"name": "Darn",
			"team": "red",
			"xp": 0,
		},
	];

	apiData.forEach((playerJson) {
		var player = Player.fromJson(playerJson);
		player.sayHello();
	});
}
```

**실습 문제**

2. 이를 상속받아 구체적인 클래스를 구현하고, 믹스인을 추가하여 추가 기능을 구현하세요.(돌고래, swimming...)

```dart
abstract class Animal {
  String name;

  Animal(this.name);

  void sound();
}

mixin Swim {
  void swim() {
    print('Swimming...');
  }
}

class Dolphin extends Animal with Swim {
  Dolphin(String name) : super(name);

  @override
  void sound() {
    print('$name makes a clicking sound!');
  }
}

void main() {
  var dolphin = Dolphin('Dolly');
  dolphin.sound();
  dolphin.swim();
}
```
