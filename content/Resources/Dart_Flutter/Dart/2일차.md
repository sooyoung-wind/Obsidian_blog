### 1. Data Types

Dart에서 기본 데이터 타입은 다음과 같습니다.

- **int**: 정수 (예: `1`, `42`)
- **double**: 부동 소수점 숫자 (예: `3.14`, `-0.5`)
- **num**: `int`와 `double`을 모두 포함하는 타입.
- **String**: 문자열 (예: `'hello'`, `"Dart"`)
- **bool**: 참/거짓 논리값 (예: `true`, `false`)

**실습 문제 1:** 변수 `a`, `b`, `c`, `d`, `e`를 각각 int, double, num, String, bool 타입으로 선언하고 값을 초기화하세요.

```dart
int a = 10;
double b = 3.14;
num c = 5.5; // num은 int와 double 모두를 포함합니다.
String d = 'Hello, Dart!';
bool e = true;
```

**실습 문제 2:** 각 변수의 타입을 출력하세요 (`runtimeType` 사용)

```dart
void main() {
  int a = 10;
  double b = 3.14;
  num c = 5.5;
  String d = 'Hello, Dart!';
  bool e = true;

  print('a의 타입: ${a.runtimeType}');
  print('b의 타입: ${b.runtimeType}');
  print('c의 타입: ${c.runtimeType}');
  print('d의 타입: ${d.runtimeType}');
  print('e의 타입: ${e.runtimeType}');
}
```

### 2. Lists

Dart의 리스트는 Python의 리스트와 유사하며, 여러 값을 하나의 배열에 저장합니다.

- 고정 길이: 길이를 변경할 수 없음.
- 가변 길이: 추가 및 삭제 가능.

**실습 문제 1:** 길이가 고정된 `List<int>`를 만들고 숫자 1~5를 저장하세요.
```dart
void main() {
  List<int> fixedList = List<int>.filled(5, 0); // 길이가 5인 고정 리스트 생성
  fixedList[0] = 1;
  fixedList[1] = 2;
  fixedList[2] = 3;
  fixedList[3] = 4;
  fixedList[4] = 5;

  print(fixedList);
}
```

**실습 문제 2:** 가변 길이 리스트를 만들고, 문자열 값 3개를 추가하고 출력하세요.
```dart
void main() {
  List<String> growableList = []; // 가변 길이 리스트 생성
  growableList.add('Apple');
  growableList.add('Banana');
  growableList.add('Cherry');

  print(growableList);
}
```

**실습 문제 3:** 리스트의 요소를 반복문으로 순회하여 출력하세요.
```dart
void main() {
  List<String> fruits = ['Apple', 'Banana', 'Cherry'];

  for (String fruit in fruits) {
    print(fruit);
  }
}
```

### 3. String Interpolation
문자열 안에서 변수를 사용하는 것을 문자열 보간법이라고 합니다.

- `$변수명` 또는 `${표현식}` 형식으로 사용.

**실습 문제 1:** 이름과 나이를 저장하는 변수 `name`, `age`를 선언하고, `"My name is [name] and I am [age] years old"`를 출력하세요.
```Dart
void main() {
  String name = 'Alice';
  int age = 25;

  print('My name is $name and I am $age years old');
}
```

### 4. Collection(컬렉션) `for`
Dart의 `for` 키워드는 컬렉션(리스트, 세트 등)을 순회하며 요소를 생성할 때 유용합니다.

**실습 문제 1:** 숫자 1~5가 포함된 리스트를 생성하고, 각 숫자의 제곱 값을 새로운 리스트로 만드세요.
```dart
void main() {
  List<int> numbers = [1, 2, 3, 4, 5];
  List<int> squaredNumbers = [for (int number in numbers) number * number];

  print(squaredNumbers); // 출력: [1, 4, 9, 16, 25]
}
```

**실습 문제 2:** 문자열 리스트에서 길이가 4 이상인 요소만 포함된 리스트를 만드세요.
```dart
void main() {
  List<String> words = ['dart', 'flutter', 'ui', 'ux'];
  List<String> longWords = [for (String word in words) if (word.length >= 4) word];

  print(longWords); // 출력: ['dart', 'flutter']
}
```

### 5. Maps
맵은 키와 값의 쌍으로 데이터를 저장합니다.
- Dart에서 맵은 `Map<KeyType, ValueType>`으로 선언.

**실습 문제 1:** 국가와 수도를 키-값으로 저장한 맵을 생성하세요.
- South Korea, Seoul
- Japan, Tokyo
- France, Paris
```Dart
void main() {
  Map<String, String> countryCapital = {
    'South Korea': 'Seoul',
    'Japan': 'Tokyo',
    'France': 'Paris'
  };

  print(countryCapital);
}
```

**실습 문제 2:** 맵에서 특정 국가의 수도를 검색하고 출력하세요.
```dart
void main() {
  Map<String, String> countryCapital = {
    'South Korea': 'Seoul',
    'Japan': 'Tokyo',
    'France': 'Paris'
  };

  String capitalOfJapan = countryCapital['Japan'] ?? 'Unknown';
  print('The capital of Japan is $capitalOfJapan');
}
```

**실습 문제 3:** 모든 키와 값을 순회하며 출력하세요.
- Map의 `forEach` 사용
```dart
void main() {
  Map<String, String> countryCapital = {
    'South Korea': 'Seoul',
    'Japan': 'Tokyo',
    'France': 'Paris'
  };

  countryCapital.forEach((country, capital) {
    print('The capital of $country is $capital');
  });
}
```

### 6. Sets

Dart의 세트는 중복되지 않는 고유한 값들의 집합입니다.

**실습 문제 1:** 숫자 1, 2, 3, 3, 4, 5를 포함한 세트를 생성하고 출력하세요 (중복이 제거되는지 확인).

```dart
void main() {
  // 중복된 값이 포함된 리스트
  List<int> numbers = [1, 2, 3, 3, 4, 5];
  
  // 리스트를 세트로 변환하여 중복 제거
  Set<int> numberSet = Set<int>.from(numbers);
  
  // 세트 출력
  print(numberSet); // 출력: {1, 2, 3, 4, 5}
}
```

**실습 문제 2:** 두 세트를 만들어 합집합, 교집합, 차집합을 구하세요.
- union : 합집합 메서드
- intersection : 교집합 메서드
- difference : 차집합 메서드
```Dart
void main() {
  // 첫 번째 세트
  Set<int> setA = {1, 2, 3, 4, 5};
  
  // 두 번째 세트
  Set<int> setB = {4, 5, 6, 7, 8};
  
  // 합집합: 두 세트의 모든 요소를 포함 (중복 제거)
  Set<int> unionSet = setA.union(setB);
  print('합집합: $unionSet'); // 출력: {1, 2, 3, 4, 5, 6, 7, 8}
  
  // 교집합: 두 세트에 모두 존재하는 요소
  Set<int> intersectionSet = setA.intersection(setB);
  print('교집합: $intersectionSet'); // 출력: {4, 5}
  
  // 차집합: setA에는 있고 setB에는 없는 요소
  Set<int> differenceSet = setA.difference(setB);
  print('차집합: $differenceSet'); // 출력: {1, 2, 3}
}
```
