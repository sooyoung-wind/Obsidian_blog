#### 데이터 과학의 정의와 구성 요소
- 데이터 과학 = 컴퓨터 과학 + 통계학 + 도메인 과학의 교집합
- IBM 정의 : 수학과 통계, 전문 프로그래밍, 고급 분석, 인공지능을 특정 주제 전문 지식과 결합
- 목표 : 데이터에 숨겨진 실행 가능한 통찰력 찾기
- 빅데이터의 특성 : Volume, Velocity, Variety, Veracity
- 풍력 분야의 데이터 유형 : SCADA data, 드론 영상, 기술자 기록 문서, 시뮬레이션 데이터
- 데이터 자체는 비용이며, 유의미한 정보를 얻지 못하면 자원 낭비

> 풍력은 도메인 지식이 없으면 접근하기가 어려운 분야

#### 풍력에너지 생애주기별 적용
- 개발 단계 : 풍력 자원 평가, 레이아웃 설계, 불확실성 정량화
- 운영 단계 : 예측적 유지보수, 제어 최적화, 부품 교체 일정 계획
- 예측 모델링 : 풍력 예측, 고장 예측 성능 최적화

#### SCADA 시스템과 데이터 수집
SCADA(Supervisory Control and Data Acquisition) 시스템은 모든 장치 제어기와 통신하여 풍력터빈, 태양광, 배터리 제어기뿐만 아니라 차단기 등의 보호장치 데이터도 수집한다. 그러나 SCADA는 운영 지원용으로 설계되어 장기 데이터 저장에는 한계가 있어, 별도의 InfluxDB 기반 데이터 수집 시스템을 구축하여 모든 데이터를 통합 저장한다. OPC 서버를 통해 SCADA의 실시간 데이터를 추출하여 기상 데이터, 기계적 측정 데이터와 함께 동기화하여 저장한다.

- 모든 장치 제어기(풍력터빈, 태양광, 배터리)와의 통신 및 제어
- 차단기 등 보호장치의 고급 데이터 수집 기능 활용
- SCADA 데이터의 한계: 운영용 설계로 장기 저장 불가, 데이터 덮어쓰기 문제  
- InfluxDB 기반 통합 데이터베이스 구축으로 영구 저장 실현
- OPC 서버를 통한 실시간 데이터 추출 및 동기화
- 전기적 데이터, 기상 데이터, 기계적 측정 데이터의 통합 저장

CompactRIO 장비 사용 - DTU 실험시설 장비

#### Data Modelling
- 목표 정의
	- 어떤 부품과 고장 종류를 검출할 것인지 문제 정의
